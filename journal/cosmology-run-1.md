# Cosmology Audit — Run 1 Journal

**Date:** 2026-04-12
**Agent:** Phase B rigorous-audit pass over iʿjāz ʿilmī cosmology claims.

## Scope

Twelve verses most frequently cited in modern "scientific miracle" literature for cosmological content:

- Q 21:30 (ratq/fatq)
- Q 51:47 (mūsiʿūn)
- Q 21:33, 36:38–40 (falak/yasbaḥūn)
- Q 55:33 (sulṭān and penetrating heavens)
- Q 41:11 (dukhān)
- Q 15:14–15 (gate in the heaven / ascent)
- Q 78:12–13 (seven shidād)
- Q 86:3 (najm thāqib)
- Q 36:38 (sun's mustaqarr)
- Q 71:15–16 (nūr vs sirāj)
- Q 79:30–31 (daḥāhā)
- Q 88:20 + 16:15 (mountains erected / rawāsī)

## Method

Three-source triangulation:
1. Classical tafsīr (Ṭabarī, Zamakhsharī, Rāzī, Qurṭubī, Ibn Kathīr) — earliest glosses.
2. Arabic lexicography (Lisān al-ʿarab, Tāj al-ʿarūs, Mufradāt) — root semantics.
3. ANE parallels (Hebrew Bible, Enochic, Talmud, Mesopotamian, Greek).

Verdict scale V1–V5 designed to distinguish overreach (V1), underdetermination (V2/V3), and genuine compatibility (V4/V5).

## Key calls made during the run

- Anchored the apologetic claims at their strongest form, not the weakest, to avoid strawmanning.
- Distinguished cases where the classical tradition *excludes* a modern reading (e.g., mūsiʿūn as participle of state, not progressive) from cases where it *underdetermines* (e.g., dukhān — any gaseous-precursor reading is possible but unmotivated).
- Flagged one minority classical reading (Mujāhid on ratq/fatq) that genuinely rhymes with modern cosmic-differentiation imagery; this raises 21:30 to V3+ territory.
- Noticed the strongest iʿjāz case in the mountain cluster is morphological (mountain roots as stake-imagery) but the verse's stated **function** (preventing sway) contradicts modern orogeny, so the apparent hit is partial.
- Tracked lexical leakage in the *nūr / sirāj* apologetic: Q 33:46 calls the Prophet *sirājan munīrā* (both lamp and nūr-derivative), which dissolves the proposed emitter-vs-reflector distinction.
- Separated the ostrich-nest folk etymology of *daḥā* from its primary meaning ("spread"); the egg-reading is a derived-noun stretch.
- Anchored *sulṭān* by its Quranic distribution (authority/warrant, never technology) to refute the space-travel reading cleanly.

## Findings distribution

- V1 (overreach): sulṭān/space-travel, thāqib/pulsars, hypoxia, seven heavens as atmospheric layers.
- V2 (weak): mūsiʿūn, daḥā-as-egg, falak/yasbaḥūn, nūr/sirāj, dukhān/nebula, sun's mustaqarr.
- V3 (ambiguous): ratq/fatq (with a lean toward V4), mountains-as-stakes (partial).
- V4: none clearly (ratq/fatq qualified).
- V5: none.

## Honest summary

The iʿjāz ʿilmī genre is a 20th-century apologetic program, not a continuation of the classical exegetical tradition. Its strongest case (ratq/fatq) is a cosmogonic topos shared with the whole ANE. Its weakest cases are etymological fabrications (thāqib, daḥā). The classical tafsīr tradition — with access to the same Arabic and stronger motivation to find anticipatory wonders — did not read these verses as hidden science.
