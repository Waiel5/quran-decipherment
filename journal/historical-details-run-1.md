# Journal — historical details run 1

## Frame

Phase B audit. Question from user: "what if something stated it existed but never existed back then." That is: does the Qurʾān make historical claims that contradict the historical record, or that are only verifiable with later archaeology, or that are otherwise distinctive to the Qurʾān vs. the 7th-c. Hijaz information environment?

Output not a polemic — a graded audit. Verdict scale A–D:
- A: plausibly accessible via oral / trade / local-memory channels
- B: accessible only via specific religious networks (Syriac Christian, Medinan Jewish, Ethiopic, Manichaean, etc.)
- C: not obviously accessible — distinctive or requiring rare channel
- D: contradicts the attested record

## Method per claim
1. Locate Quranic loci exactly.
2. State the classical tafsīr reading (the medieval Muslim consensus).
3. Survey modern scholarly / historical-critical / archaeological readings — including apologetic and polemical poles.
4. Render a single graded verdict with one-line rationale.
