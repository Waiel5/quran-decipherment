**Retained deliberately. Not to be deleted, and not to be cited.**

`20260807T101421Z` was produced by a **throwaway copy** of `scripts/h-new-2850.py` with
`N_PERM` reduced from 10,000 to **60**, executed to prove the pipeline ran end to end before
the real run touched the repository. The copy was meant to write outside the repository; the
edit that was supposed to redirect its output path **did not match the source line and
silently failed**, so it wrote here instead.

Two things about that directory are therefore true and must be read together:

1. **Its `manifest.json` is honest about the permutation count** — it records
   `"n_perm": 60`, so the file states its own limitation.
2. **Its `manifest.json` names the wrong script.** It records
   `findings/phase-b-hypotheses/scripts/h-new-2850.py`, but the file that executed was a
   modified copy. Every permutation p-value in its `result.json` is floored at
   `1/61 ≈ 0.0164` and means nothing.

Everything in it that does **not** depend on permutation — root counts, pooled rates, gaps,
Mantel–Haenszel and Cochran–Mantel–Haenszel statistics, the exact sign tests, the census and
the rosters — was computed by identical code and agrees with the real runs.

**It is retained rather than removed** because `h-new-2540-form-v-valency.md` §8.1 records a
prior breach of run immutability by me, and the standing correction there is explicit: a run
directory that should not have been written is handled by **re-running to an additional
directory and keeping both, with the reason recorded** — never by deleting evidence.

The citable runs are the ones whose manifests record `"n_perm": 10000`.
