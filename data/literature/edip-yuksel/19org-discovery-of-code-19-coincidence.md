# Was the Discovery of the Code 19 a Coincidence?

**Source:** https://19.org/blog/was-the-discovery-of-the-code-19-a-coincidence/
**Author:** Edip Yüksel (attributed)
**Fetched:** 2026-04-12

## Main Claims

The article argues the Code 19's discovery was not coincidental but divinely orchestrated.

**Central Timing Coincidence:**
"The number 19 is mentioned only in a chapter called 'The Hidden,' the 74th chapter of the Quran. Juxtaposing these two numbers yields 1974, exactly the year in which the code was deciphered."

**Additional Correlations:**
- 19 × 74 = 1406 (lunar years between Quran's revelation and discovery)
- The discoverer's name derivatives (RShD/"guidance") appear exactly 19 times in the Quran
- The first two verses of Chapter 74, when numerically calculated using Arabic letter values, sum to 1974

**Historical Context:**
Dr. Rashad Khalifa began computerized research in 1969 and discovered the mathematical system in 1974. The article refutes mathematician Martin Gardner's 1980 claim about a 1972 publication mentioning Code 19, asserting Khalifa had no knowledge of the code before 1974.
