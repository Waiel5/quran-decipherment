## Project Overview
Tanzil is a Quranic initiative established in 2007 with a focused goal: "produce a highly verified Unicode Quran text to be used in Quranic websites and applications."

## Core Problems Addressed
The project emerged in response to widespread errors in digital Quran texts. The founders noted that erroneous versions had proliferated online, making it nearly impossible to locate accurate verses without consulting printed manuscripts.

Primary sources of corruption included:

- **Incomplete diacritics** from manually-added marks to diacritic-less copies
- **Script conversion errors** when transitioning between Uthmani and Imlaei formats
- **Technical encoding limitations** (older character sets lacked essential diacritical marks)

## Verification Methodology

The project employs a three-phase approach:

1. **Automatic Text Extraction** — Multiple authentic sources were collected and converted to a standardized format for comparative analysis

2. **Rule-Based Verification** — Grammatical and recitation rules were applied programmatically to validate the text and generate variant formats

3. **Manual Verification** — "The Quran text produced was examined thoroughly against Medina Mushaf, and a checksum for each letter and diacritic was calculated"

## Available Text Types
- **Simple**: Plain, Minimal, or Clean variants
- **Uthmani**: Standard or Minimal versions

## Output Formats
- Text (with or without verse numbers)
- XML
- SQL (MySQL dump)

## Optional Features
Users can customize downloads to include:
- Pause marks
- Sajdah signs (۩)
- Rub-el-hizb signs (۞)
- Tatweel marks for superscript alefs

## Results & Impact
Since its 2008 release, the project reports zero typo submissions despite millions of monthly active users across major Quranic platforms.
