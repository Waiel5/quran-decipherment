### Q 15:1 ↔ Q 12:2, Q 13:1, Q 14:1 (post-muqaṭṭaʿāt book-reference)

Q 15:1 *تلك آيات الكتاب وقرآن مبين* fits the muqaṭṭaʿāt → book-reference pattern (cross-finding-008-muqattaat-book-intro-markers). Parallel openers:

### Q 15:9 ↔ Q 76:23 ↔ Q 38:8 ↔ Q 15:6 (revelation-of-dhikr cluster)

The *naḥnu nazzalnā* + *al-dhikr* construction cluster:
- **Q 15:9** *innā naḥnu nazzalnā al-dhikra wa-innā lahu la-ḥāfiẓūn* — divine-self-attribution + revelation-action + revealed-text-object + divine-guardianship (corpus-UNIQUE combined per Q015-F-02).
- Q 76:23 *innā naḥnu nazzalnā ʿalayka al-Qurʾāna tanzīlan* — divine-self-attribution + revelation-action + revealed-text-object (al-Qurʾān instead of al-dhikr).
- Q 38:8 *anzala ʿalayhi al-dhikru min bayninā* — disbelievers' polemic against the Prophet receiving al-dhikr (NEGATIVE form).
- Q 15:6 *yā ayyuhā alladhī nuzzila ʿalayhi al-dhikr innaka la-majnūn* — disbelievers' mocking address against the Prophet receiving al-dhikr.

The FOUR verses span the divine-self-attribution → divine-guardian (Q 15:9) → divine-1st-pl-revelation (Q 76:23) → disbelievers' negation-of-divine-revelation (Q 38:8 + Q 15:6) progression. Q 15 contains TWO of these four verses (vv. 6 and 9), structurally bookending the surah's opening.

### Q 15:26-27 ↔ Q 32:7-9, Q 36:77-83, Q 38:71-76 (creation-from-clay-and-fire cluster)

Q 15:26-27 (mankind from *ṣalṣālin min ḥamaʾin masnūn*; jinn from *nāri al-samūm*) is parallel to:
- Q 32:7-9 (mankind from *ṭīn* / *salāla min sulālat min māʾ mahīn*)
- Q 36:77-83 (mankind's creation-typology theme)
- Q 38:71-76 (mankind from *ṭīn* — Adam-creation prelude)

Q 15:26-27 has the corpus-UNIQUE pairing of *ṣalṣāl + ḥamaʾ + masnūn* + *nāri al-samūm* (clay + scorching-fire) — the two-substance creation-typology that distinguishes humans from jinn.

### Q 15:73-74 ↔ Q 11:82, Q 105:4 (sijjīl brimstone cluster)

Q 15:74 *amṭarnā ʿalayhim ḥijāratan min sijjīl* — brimstone rained on Lot's tribe — has corpus-parallel:
- Q 11:82 *amṭarnā ʿalayhā ḥijāratan min sijjīlin manḍūd* (Lot's tribe destruction in Hūd)
- Q 105:4 *tarmīhim bi-ḥijāratin min sijjīl* (the Companions of the Elephant)

The *sijjīl* (brimstone / clay-stone) lemma is corpus-rare (3 attestations). Q 15:74's cluster with Q 11:82 + Q 105:4 represents the corpus's brimstone-destruction tradition.

### Q 15:87 ↔ Q 39:23 (al-mathānī cluster)

Q 15:87 *sabʿan min al-mathānī* — the seven oft-repeated. Cross-reference: Q 39:23 *Allāh nazzala aḥsana al-ḥadīthi kitāban mutashābihan mathāniya* — God sent down the best discourse, a Book consistent and oft-repeating. The Q 39:23 *mathāniya* is the only other corpus-attestation of the *mathānī* root in this revelation-context.

The classical interpretation of Q 15:87's *al-mathānī* = al-Fātiḥa is anchored at Bukhārī #4498 (verified — see `04-hadith-corpus.md`).
