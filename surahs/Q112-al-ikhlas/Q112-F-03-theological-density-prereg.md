# Q112-F-03 — Pre-registration: Q 112 theological-proposition density

## Hypothesis (H1)

Q 112 al-Ikhlāṣ encodes 4 distinct theological propositions in 4 verses (1 proposition per verse), corresponding to a **theological-density-per-word** of 4/15 = 0.267 propositions per word.

Hypothesis: this density is **corpus-extreme** within short surahs (≤6 verses) when each surah's theological-proposition count is annotated by the same 4-corner kalām taxonomy of [[Q112-al-ikhlas/02-content-analysis|02-content-analysis §2]]: (i) divine unity, (ii) divine self-sufficiency, (iii) divine non-procreation, (iv) divine incomparability — interpreted as 4 of N propositions in a *kalām al-tawḥīd* taxonomy.

Because exhaustive corpus-wide annotation is not feasible from disk in this run, this is a **descriptive-comparison test** rather than a strict statistical test:
- Compare Q 112's 4-proposition / 15-word density to the project's 4-cell typology peer surahs (Q 109, Q 113, Q 114, Q 1).

## Method

1. For each comparator surah, manually identify the count of *distinct* theological propositions encoded.
2. Normalize per word-count.
3. Rank.

## Direction

LOCKED: Q 112 has highest theological-proposition-per-word density among comparators.
