## 9. Honest limits

1. **Cluster cohesion is FR-roots-specific**. Other distance metrics (NCD, char-n-gram, contextual embeddings) untested for this cluster. Similar to [[h-new-710-translation-invariance|H-NEW-710]]'s NULL on translation-invariance, the result is rules-tuple-specific.
2. **The muʿawwidhāt-3 cluster's tightness is partly an effect of all 3 surahs being short (mufaṣṣal-qiṣār)**. Short surahs naturally have similar root-distributions weighted toward corpus-modal vocabulary. **However**, the cluster cohesion p=0.0006 is computed against a null that DOES include other short surahs in random samples; the cluster is still corpus-extreme tight.
3. **The cell-spanning property** (Q 113 in *iʿjāz al-fawāṣil-pure*; Q 112+114 in *iʿjāz al-maʿnā*) is post-hoc cell-membership reading; the cells were defined before this cluster synthesis but informed by the surahs' signatures. The cluster-spans-2-cells observation is descriptive, not pre-registered.
4. **Q 113's #1 nearest is Q 108 al-Kawthar, not its cluster siblings**. The muʿawwidhāt cluster is locally-tight but Q 113 has a non-cluster nearest neighbour. This is the asymmetric-tightness property documented in Q114-F-03.
